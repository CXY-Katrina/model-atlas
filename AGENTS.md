## Agent skills

### Skill source policy

- Treat every skill supplied by the Superpowers plugin or repository as unavailable for this project. Do not invoke or recommend those skills.
- Skills installed from [mattpocock/skills](https://github.com/mattpocock/skills) are allowed and follow their normal trigger rules.

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-role label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.
